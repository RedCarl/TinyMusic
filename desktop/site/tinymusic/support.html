第一次使用

  1. 准备一个 S3 兼容存储桶（AWS S3、Cloudflare R2、MinIO 等）、一个 WebDAV 服务器，或一个本地 / iCloud Drive 文件夹。
  2. S3 填 endpoint、region、bucket、prefix、Access Key 和 Secret Key；WebDAV 填服务器地址、根目录、用户名和密码；文件夹直接从「文件」里选择（只读）。
  3. 桶内按 前缀/歌单/歌手 - 歌名.m4a 放文件；同名 .lrc 和 .jpg/.png/.webp 会作为歌词和封面。
  4. 保存后回到资料库，选择歌单播放。

离线缓存

在歌单或歌曲上点“缓存”，App 会用后台 URLSession 把音频、歌词、封面存进沙盒。缓存只用于 App 内播放，不能导出或分享，不出现在「文件」App 里，也不会进入 iCloud 备份。

iCloud

S3 密钥、WebDAV 用户名和密码写入 Keychain；开启 iCloud 钥匙串后可在自己的设备间同步。S3 / WebDAV 地址、bucket、prefix、缓存上限、仅 Wi-Fi、EQ 等非敏感设置走 iCloud Key-Value Storage；文件夹授权只保存在本机，换设备需重新选择。离线缓存不同步。

常见问题

为什么歌单是空的？检查 prefix 是否和桶内目录一致，以及 Access Key 是否有 ListBucket / GetObject 权限。

为什么只能看不能收藏？本地 / iCloud 文件夹是只读盘，不写 favorites.json，收藏入口会隐藏；S3 只读密钥写入失败时会提示。

为什么播放失败？确认 endpoint 使用 HTTPS、bucket 允许 CORS 或公开读取，或使用预签名 URL 所需权限。

缓存和下载有什么区别？缓存只是 App 内部的离线副本，不能导出、分享或搬到别的播放器。

隐私

App 不收集账号、播放记录或缓存内容，只连接你自己的网盘、选择的文件夹与 Apple 的 iCloud / Keychain 服务。详见 隐私政策。

Getting started

  1. Prepare an S3-compatible bucket (AWS S3, Cloudflare R2, MinIO and similar), a WebDAV server, or a local / iCloud Drive folder.
  2. For S3, fill in endpoint, region, bucket, prefix, Access Key and Secret Key; for WebDAV, enter the server address, root folder, username and password; for a folder, pick it from Files (read-only).
  3. Lay out files as prefix/playlist/artist - title.m4a; a matching .lrc and .jpg/.png/.webp become the lyrics and cover.
  4. Save, go back to the library and pick a playlist to play.

Offline cache

Tap "Cache" on a playlist or a track and the app downloads the audio, lyrics and cover into its sandbox with a background URLSession. The cache is for in-app playback only: it can't be exported or shared, never shows up in the Files app, and is excluded from iCloud backup.

iCloud

S3 keys and WebDAV username / password go into the Keychain, and sync across your own devices when iCloud Keychain is on. Non-sensitive settings — S3 / WebDAV address, bucket, prefix, cache cap, Wi-Fi only, EQ — use iCloud Key-Value Storage; folder access stays on this device, so you reselect it on a new device. Offline cache is never synced.

FAQ

Why is the playlist empty? Check that the prefix matches the folder layout in your bucket, and that the Access Key can ListBucket and GetObject.

Why can I only read, not favourite? Local / iCloud folders are read-only drives, so TinyMusic never writes favorites.json and hides favourites; a read-only S3 key shows an error if the write fails.

Why does playback fail? Make sure the endpoint uses HTTPS, the bucket allows CORS or public reads, or that the key may sign URLs.

How is the cache different from a download? The cache is only an offline copy inside the app; you can't export it, share it or move it to another player.

Privacy

The app collects no accounts, play history or cached content. It talks only to your own drives, the folders you choose, and Apple's iCloud / Keychain services. See the privacy policy.
